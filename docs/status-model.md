# ステータスモデル

エターナルリターンにおける各ステータス数値の意味と算出方法をまとめる。

## 概要

すべての実験体は共通するステータス項目を持つが、その値は実験体の種類、およびその状態（レベル、熟練度、装備、バフなど）によって算出される。

## ステータスの構成要素

実験体の最終ステータスは、複数の要素を合成して算出される。

- 選択された実験体
- 実験体のレベル
- 武器熟練度
- 防御熟練度
- 移動熟練度
- 装備
- バフ・デバフ

これらの「ユーザが選択する要素」から、ステータスが一意に算出される。

### ステータス各値の構成要素

各ステータスは、以下の要素を合成して算出される。各要素はステータス値の種類によって存在するものとしないものがある。

- 要素A: 実験体自身の値（基礎値・レベル比例値）
  - 基礎値 + (現在レベル - 1) * レベル比例ステータス
- 要素B: 装備による加算量（固定値・比率値・レベル比例値）
  - 固定値：装備による加算量(固定値)
  - 比率値：装備による加算量(比率値)。%表記されている。
  - レベル比例値：装備による加算量(レベル比例値) * 現在レベル
- 要素C: バフによる加算量
  - バフによる加算量。加減算・乗算のほか、既存のステータスを上書きする固定値の場合もある。
- 熟練度など、その他の要素。個別に記載している。

要素Cはあらゆるステータス値に存在しうるため、以下に示す一覧の算出方法ではすべて省略している。

### 要素の合成順序

複数の要素（要素A/B/C）は、それぞれ「単純加算」「比率として乗算」「値の上書き」のいずれかの方法で
合成される。実際の合成は次の順序で行われる。

1. 「単純加算」に分類される要素をすべて合計する。このうち実験体自身の値（要素A）だけを別途合計したものを
   「基礎合計」と呼ぶ。
2. 「比率として乗算」に分類される要素をすべて合計し、1の合計に対して乗算する（%として上乗せする）。
3. 「値の上書き」に分類される要素が1つでもあれば、そこまでの計算結果を無視してその値で上書きする
   （複数ある場合は最後に適用されたものが優先される）。
4. 上記の結果から「基礎合計」を差し引いた値を「追加分」と呼ぶ。これは実験体自身の基礎値・レベル比例値・
   熟練度による上昇分を除いた、装備・バフ由来の上昇分にあたる。ダメージ計算のレシオで「追加攻撃力」等
   （[ダメージ計算モデル](./damage-model.md)の例3参照）が参照するのはこの値。
5. 上限（max）が設定されていれば最後にクランプし、既定の桁数で**切り捨て**る（四捨五入ではない）。

「値の上書き」に分類される要素は、現状では実験体固有の恒久パッシブ効果や装備固有アビリティによる
恒久ステータス変換にのみ用いられており、一時的なバフ・デバフによる上書きは未実装
（[既知の課題](./known-issues.md)参照）。

### ステータス各値の端数処理・丸め

ステータスの値ごとに固有の桁数で丸められる。表記上はその桁で四捨五入されるが、ゲーム内部では少なくとも+1桁分以上の精度で計算されていると推測される。

## ステータス一覧

### 体力・回復

#### maxHp（最大体力）

小数点以下: 0桁
実験体の最大体力。0になると死亡する。
要素A(基礎値) + 要素A(レベル比例値) + 要素B(固定値) + 要素B(レベル比例値)

#### hpRegen（体力自然回復）

小数点以下: 2桁
1秒ごとに自然回復する体力の量。
((要素A(基礎値) + 要素A(レベル比例値)) * 要素B(比率値)

### 防御

#### defense（防御力）

小数点以下: 0桁
受けるダメージを軽減するステータス。
要素A(基礎値) + 要素A(レベル比例値) + 要素B(固定値)

#### preventBasicAttackDamagedRatio（基本攻撃被ダメージ減少率）

小数点以下: 1桁（%表記）
基本攻撃によって受けるダメージを割合で軽減するステータス。
防御熟練度 * 熟練度比例値(全実験体共通値)

#### preventBasicAttackDamaged（基本攻撃被ダメージ減少・固定値）

小数点以下: 0桁
基本攻撃によって受けるダメージを固定値で軽減するステータス。
実験体: ガーネットにのみ存在。パッシブ(T)スキル効果による。

#### preventSkillDamagedRatio（スキル被ダメージ減少率）

小数点以下: 1桁（%表記）
スキル攻撃によって受けるダメージを割合で軽減するステータス。
防御熟練度 * 熟練度比例値(全実験体共通値。基本攻撃とは異なる値)

### 攻撃

#### attackPower（攻撃力）

小数点以下: 0桁
基本攻撃の威力、および攻撃力型実験体のスキル威力を決定するステータス。
要素A(基礎値) + 要素A(レベル比例値) + 要素B(固定値) + 要素B(レベル比例値) + 要素C + 武器熟練度 * 熟練度比例値。
熟練度比例値を持っているのは実験体: イアンのみ。

#### increaseBasicAttackDamageRatio（基本攻撃増幅）

小数点以下: 1桁（%表記）
基本攻撃の威力を割合で増幅するステータス。実験体: イアン以外の攻撃力型実験体が保有するほか、一部装備が有する。
武器熟練度 * 熟練度比例値(実験体と武器種の組み合わせごとに固有) + 要素B(レベル比例値)

#### attackSpeed（攻撃速度）

小数点以下: 2桁
1秒あたりに可能な基本攻撃の回数。一部スキルの効果時間中を除き、2.5を超えない。
装備やスキルによる増加値は%で表記される。
(実験体の基礎値 + 武器種ごとに固有の基礎値) * (100% + 武器熟練度 * 武器熟練度比例値 + 要素B(比率値))

補足: 武器熟練度は「攻撃力/スキル増幅/基本攻撃増幅のいずれか1種類への比例効果」と「攻撃速度への比例効果」を
常に両方持つ（武器種によらない）。前者の種類にかかわらず、攻撃速度への効果は必ず加算される。

#### criticalStrikeChance（致命打確率）

小数点以下: 0桁（%表記）
基本攻撃が致命打（いわゆるクリティカルヒット）となる確率。
一部実験体はパッシブスキルにより致命打が発生しないが、ステータス自体はどの実験体も保有しうる。
100%を超えない。
要素B(固定値)

#### criticalStrikeDamage（致命打ダメージ量）

小数点以下: 0桁（%表記）
致命打の基本増幅率に加算される、致命打発生時の威力値。装備ステータスとして%表記される。詳細は[ダメージ計算モデル](./damage-model.md)を参照。
要素B(固定値)

### スキル

#### skillAmp（スキル増幅）

小数点以下: 0桁
スキル増幅型実験体のスキル威力を決定するステータス。
((要素B(固定値) + 要素B(レベル比例値)) * (100% + 要素B(比率値: skillAmpRatio/uniqueSkillAmpRatio) + 武器熟練度 * 武器熟練度比例値)

### クールダウン

#### cooldownReduction（クールダウン減少）

小数点以下: 0桁
スキルのクールダウン時間を割合で減少させるステータス。減少率(%) = CDR / (100 + CDR) * 100。
減少率は小数点以下0桁で四捨五入される。
要素B(固定値)

#### ultCooldownReduction（究極技クールダウン減少）

小数点以下: 0桁
Rスキル、いわゆるアルティメットのクールダウン時間を割合で減少させるステータス。通常のCDRに加算してRにのみ適用される。
要素B(固定値)

#### tacticalSkillCooldownReduction（戦術スキルクールダウン減少）

小数点以下: 0桁
戦術スキル（Fスキル）のクールダウン時間を割合で減少させるステータス。通常のCDRに加算してFにのみ適用される。
この計算機では、現在戦術スキルのツールチップを表示していないため、この値は参照されていない。
要素B(固定値)

### 防御貫通

#### penetrationDefense（防御貫通・固定値）

小数点以下: 0桁
最終的なダメージ計算の際に、相手の防御力を定数値ぶん無視する（減少させて計算する）ステータス。
要素B(固定値)

#### penetrationDefenseRatio（防御貫通・割合値）

小数点以下: 0桁（%表記）
最終的なダメージ計算の際に、相手の防御力を割合ぶん無視するステータス。
要素B(固定値)

### 回復・吸収

#### lifeSteal（ダメージ吸血）

小数点以下: 0桁（%表記）
基本攻撃およびスキル、すべての与ダメージに比例して自身の体力を回復するようになるステータス。
複数体にヒットしうる範囲攻撃は表示値の33%が適用される仕様があるが、現在この計算機では表現していない。
要素B(固定値)

#### normalLifeSteal（生命力吸収）

小数点以下: 0桁（%表記）
基本攻撃による与ダメージに比例して自身の体力を回復するようになるステータス。
要素B(固定値)

#### healerGiveHpHealRatio（与える回復増加）

小数点以下: 0桁（%表記）
スキルによって自身または味方の体力を回復する効果量を割合で増幅させるステータス。なお、シールドに対しては適用されない。
要素B(固定値)

### 耐性・移動

#### tenacity（状態異常耐性）

小数点以下: 0桁（%表記）
エアボーンを除く被CC時間を割合で減少させるステータス。
要素B(固定値)

#### moveSpeed（移動速度）

小数点以下: 2桁
実験体が移動するときの速度。単位はm/s。

(要素A(基礎値) + 要素B(固定値)) * (100% + 要素B(比率値) + 移動熟練度 * 熟練度比例値(全実験体共通))の値を計算し、
その値に対してバフ・デバフによる割合適用をした「生の値」に対して、次の補正を行った値。

- 0未満：　1（最小値）に補正。
- 0 ~ 2：　1 + 生の値 * 50%。
- 2 ~ 4.2：　そのまま適用。
- 4.2 ~ 5： 4.2 +　(生の値 - 4.2) * 80%。
- 5以上： 4.84 + (生の値 - 5) * 60%（4.84は4.2区間の上限式に5を代入した値: 4.2+(5-4.2)*80%）。

出展: https://playeternalreturn.com/posts/news/2363

#### slowResist（移動速度減少抵抗）

以前のバージョンで存在していたが、ごく最近廃止された。

### 視界・射程

#### sightRange（視界範囲）

小数点以下: 1桁
昼時間帯において戦場の霧が晴れる範囲。
基礎値(全実験体共通) + 要素B(固定値)

#### attackRange（基本攻撃射程）

小数点以下: 1桁
基本攻撃を行える範囲。
基礎値(全実験体共通) + 武器種ごとに固有の基礎値 + 要素B(固定値)

### 特殊

#### adaptiveForce（適応型能力）

小数点以下: 0桁
実験体・武器の組み合わせに応じて、攻撃力またはスキル増幅のどちらかに加算されるステータス。
実験体・武器の組み合わせが攻撃力型である（武器熟練度比例ステータスが攻撃力または基本攻撃増幅である）場合、1倍が攻撃力に加算される。
実験体・武器の組み合わせがスキル増幅型である（武器熟練度比例ステータスがスキル増幅である）場合、2倍がスキル増幅に加算される。
要素B(固定値)

### 召喚体ステータス

一部の実験体はスキルなどによって「召喚体」を生成する。そのステータスは実験体のレベルやスキルレベルによって決定される。
詳細な計算式は各実験体のスキル解説を参照のこと。

### 補足

装備のステータスはkey名に「unique」が付いているものがある（例：uniqueSkillAmpRatio）。
これらは「固有ステータス」であり、重複して装備しても効果は加算されず、最大値のみ適用される。
uniqueが付く値の最大値 + uniqueが付かないものの合計値　が装備による値。
ほとんどのステータス値はuniqueが一切存在しないか、逆にuniqueしか存在しない。
