# ダメージモデル

エターナルリターンにおけるダメージ・シールド・回復などの効果量の算出方法をまとめる。

## 威力の算出

ツールチップに表記される攻撃の威力（仮想的の防御ステータスを想定しない基本値）は、次のような「レシオ」から算出される。

### 例1: 100 + スキル増幅の120%

特定のステータス値のx%などの係数はスキルごとに固有の値が設定されている。ステータスに依存しない部分を「基礎値(base)」と呼び、ステータスに依存する部分を「比例係数」と呼ぶ。

補足: 「スキル増幅」は、「あらゆるスキルの威力を後から底上げする」ような特殊なステータスではない。実態は攻撃力に相当する、スキル増幅型実験体の主要な攻撃用ステータス（いわゆる魔力/APに近い）であり、攻撃力と同様に個々のスキルのレシオへ比例係数として組み込まれているに過ぎない。プレイヤーには自明だが、初見では「スキル増幅を上げれば全スキルの最終ダメージが増える」と誤解しやすいため注意する。

### 例2: [10,20,30,40,50] + 最大体力の5%

基礎値または比例係数が配列になっている場合、[]内の数値は[スキルのレベル]に対応している。つまり、スキルレベル1〜5の順で威力が増加するスキルである。
スキルレベルは通常スキル(Q,W,E,R)が5、究極技(R)およびパッシブ(T)が3。戦術スキル(F)が2。
ただし、一部実験体は固有のスキルレベル上限を持つ。

### 例3: 100 + 追加攻撃力の150%

比例係数に「追加」という単語がついている場合、現在のステータス値 - その実験体の現在Lvにおける基礎値に対して比例係数が適用される。
すなわち、装備による当該ステータス上昇量（レベル比例値を含む）+ バフなどによる上昇量に対して比例係数が適用される。
ここで言う「バフ」は、実験体に対してパッシブ効果によって与えられる恒久ステータスも含む。たとえば、実験体: ヒスイは攻撃速度に応じて攻撃力に割合増加効果が与えられるが、「追加攻撃力」はこの値を含む。

### 例4: 100 + 対象の最大体力の5%

対象のステータスに応じて変化する効果量は、実験体単体での効果量計算（シンプルモード）においては不定である。これを「動的な効果量」と呼び、シンプルモードではそのまま「（+対象の最大体力の5%）」のように記述する。
対戦モードではこの部分も計算して表記する。

### 例5: ( [80,105,130,155,180] + 攻撃力の30% + スキル増幅の75% ) + (致命打確率の65%)%

ごく一部の実験体のスキルは、「直前までの合計値に対し、特定の方法で算出された割合値を加算する」という計算式を持つ。例5は、第1項の合計値に対して、致命打確率の65%ぶんの割合を追加、すなわち「100% + 致命打確率の65%を乗算」する。

### 補足: レシオ項目ごとの合成方法（加算 / 乗算）

レシオを構成する各項目（基礎値、比例係数の対象ステータス）は、素朴に合計へ**加算**されるものと、
それまでの合計に対して**乗算**（割合として上乗せ）されるものが混在している。

- 加算: 基礎値、レベル、最大体力、追加最大体力、防御力、攻撃力、追加攻撃力、追加攻撃速度、
  スキル増幅、スタック、ゲージ
- 乗算: 致命打確率（ステータスの致命打確率 × 指定比率ぶんを乗算）、基本攻撃増幅
  （指定値によらず、下記補足の通り「基本攻撃増幅」ステータスの値をそのまま100%適用）

## ダメージ種別

### 基本攻撃ダメージ

基本攻撃によって与えられるダメージ。一部実験体は「基本攻撃ダメージを与えるスキル」を有することがある。
また、「基本攻撃にスキルダメージが追加される」「基本攻撃がスキルダメージ属性のみに置き換わる」などの効果が適用される場合がある。

#### 基本攻撃の威力

基本攻撃の威力は、攻撃力の100% * (100% + 基本攻撃増幅)で求められる。
ただし、次の例外がある。

- 武器種「双剣」による基本攻撃は、攻撃力の80% * (100% + 基本攻撃増幅)を2連続で行う。
- 武器種「突撃小銃」による基本攻撃は、攻撃力の[40%、30%、30%]にそれぞれ基本攻撃増幅ぶんを適用した3連続攻撃である。

これらの複数弾攻撃は、仕様上必ず全弾ヒットするため、テーブル上は合計値だけを表示する。
ガーネットTによる基本攻撃ダメージ減少は、各ヒットにそれぞれ適用される。
これらの威力はパッチによって変動することがある。

補足: レシオ構造体上の`basicAttackAmp`という項目は、値そのものに意味を持たない（現仕様では常にダミー値100が入るだけの、項目の有無だけを見るフラグ）。この項目が存在する場合、指定された数値に関わらず、常にステータスの「基本攻撃増幅（`increaseBasicAttackDamageRatio`）」の値をそのまま100%として乗算する特別処理になっている。非自明な挙動なので注意する。

また、一部実験体は特別な計算を行う。

### スキルダメージ

スキルによって与えられるダメージ。多くの装備スキルダメージも「スキルダメージ属性」である。

### 固定ダメージ（防御無視）

仮想敵の防御力やダメージ軽減効果を一切無視し、威力がそのまま与ダメージとなる。
ダメージの発生源側に与ダメージ増加バフがかかっている場合、威力が増加することがある（現時点で検証不足。バフ効果計算機能の実装に応じて追加検証予定）。

## ダメージ軽減・防御計算

### 防御力による軽減

ダメージを与える発生源に対して仮想敵を想定するとき、それが固定ダメージでなければ、防御力に応じて次の軽減率が適用される。

軽減率(%) = 100% - 100 / (100 + 仮想敵の防御力) * 100

### 防御力貫通の適用順序

ダメージの発生源である実験体が防御貫通ステータスを有する場合、仮想敵の防御力が貫通値ぶん低いものとして計算する。
固定値の防御貫通と割合の防御貫通を両方持つ場合、割合成分は貫通適用後の防御力ではなく、**仮想敵の防御力
（バフ・デバフ適用後、防御貫通適用前の値。[ステータスモデル](./status-model.md)の`defense`項目でいう
「結果A」）**に対して計算される（先に割合分を差し引き、そこから固定値分をさらに差し引く）。

### 被ダメージ減少（増加）系効果との合成順序

ダメージの種類に応じて、さらに追加の軽減率が適用される場合、防御力の軽減を行った結果のダメージに対して、さらに乗算でダメージを軽減する。
基本攻撃属性とスキル攻撃属性では軽減率が異なる。

また、固定値軽減はこれらの乗算軽減をすべて適用したあとに減算される。

## 致命打（クリティカル）

基本攻撃（または基本攻撃属性のスキル）に対して、実験体の致命打確率に応じて発生しうる。
発生した場合、175%の威力が適用される。この比率はパッチによって変更される可能性がある。
実験体が致命打ダメージ量のステータスを有する場合、175%にその値を加算した割合値が適用される。

## シールド

実験体が受けるダメージを一定時間・一定量だけ肩代わりする防御効果。
サポート特性「超再生」を選択している実験体が発生源のシールドは、一定の割合が増加する。

## 回復

実験体の体力を回復させる効果。healerGiveHpHealRatio（回復力増加）ステータスを有する実験体が発生源である（自己回復の場合、自分自身）場合、その割合ぶんだけ回復量が増加する。
サポート特性「超再生」を選択している実験体が発生源の回復量は、上記の結果にさらに一定の割合を乗算した効果量となる。

## スキルダメージ増加効果

「与えるスキルダメージを増加する」効果はレアだが、特性「増幅ドローン」、装備スキル「執行人」「予熱 -
増幅」に存在する（他にも存在する可能性がある）。これらは同じ効果に見えて、実際には適用対象が異なることが
実験で判明している。

### 増幅ドローン

- 雪Qで発生する強化基本攻撃やエイデンQなど、「基本攻撃ダメージを与える」スキルには**非適用**
- 装備効果によるスキルダメージには**適用**
- 戦術スキルには**適用**

### 執行人・予熱-増幅

- 雪Qで発生する強化基本攻撃やエイデンQなど、「基本攻撃ダメージを与える」スキルにも**適用**
- 装備効果によるスキルダメージには**非適用**
- 戦術スキルには**非適用**

### 共通（両方に適用される）

- ナタポンなど「基本攻撃に追加でスキルダメージが乗る」効果はスキルダメージ部分に適用される
- パッシブスキル、武器スキルには適用される

### 解釈

増幅ドローンは「ダメージ種別がスキルダメージであれば適用」、執行人・予熱-増幅は「発生源が実験体スキル
（武器スキルを含む）であれば適用」という、判定軸が異なるルールだと解釈できる。バフ・デバフ計算機能の
実装時、この2種類の適用条件を区別できる設計にする必要がある。

## その他の効果量

ダメージやヒール効果の他、移動速度増加などのバフ効果や、攻撃のヒット数などが効果量レシオから算出されることがある。

## 複数ヒット、割合適用(multiplier)

この計算機では、複数回ヒットしうるスキルが全ヒットした場合の予測ダメージ量や、「特定の条件下で効果量がx%になる」スキルの、当該状態における予測効果量も含めてテーブルが表示される。

これらの最終的な倍率要素をmultiplierと呼ぶ(ゲーム中の呼称ではなく、この計算機独自の呼称)。multiplierはすべての計算の最後に適用される。

## 計算順序まとめ

### 効果量

1. レシオから威力を計算する。
2. 基本攻撃属性かつ、致命打が発生する攻撃の場合、致命打発生時のダメージ量も並列して求める。
3. それが回復効果であり、かつ発生源が「与える回復増加」ステータスを有する場合、その割合ぶんを追加する。
4. 複数ヒット・割合適用を行う項目の場合、それらを適用する。

### 最終ダメージ量

仮想敵に対して与えられる、固定ダメージや回復・シールド以外のダメージに対して、以下の順で軽減・増加処理が行われる。

1. 仮想敵の防御力による軽減を適用する。この防御力は、発生源の防御貫通ステータスぶんだけ低いものとして扱う。
2. ダメージが基本攻撃ダメージまたはスキルダメージであれば、仮想敵の対応するダメージ減少ステータス割合ぶんだけダメージを軽減する。
3. 条件に合致する場合、ガーネットTの基本攻撃ダメージ減少を適用する。
